Privacy Policy

App: gcalcli personal · Last updated: October 30, 2026

This policy explains how the app "gcalcli personal" ("the app") handles Google user data. The app is a personal tool used only by its developer with the developer's own Google account.

Data the app accesses

With the owner's permission, the app accesses Google Calendar data through the Google Calendar API: calendar lists and event details (title, time, location, description). It can also create events when the owner asks.

How the data is used

The data is used only to show the owner their own schedule and to add events the owner requests. It is not used for advertising, profiling, or any other purpose.

Storage

The app runs on the owner's own computer. The Google sign-in token is stored in a local file on that computer. Calendar data is not stored on any server operated by the developer.

Sharing

The app does not sell, share, or transfer Google user data to third parties. Calendar text may be passed to an AI model chosen and configured by the owner so that it can write the owner's own summary; it is not used for any other purpose.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

The owner can revoke access at any time at myaccount.google.com/permissions and delete the local token file from their computer.

Contact

Questions: open an issue in this site's GitHub repository.
